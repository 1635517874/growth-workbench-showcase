# 热点工作台｜TelyClaw Growth Radar

> 在线体验：https://telyclaw-growth-1635517874.netlify.app/  

个人作品展示项目，用于介绍 AI 社媒趋势监测与内容增长工作台的产品流程、线上界面和实现方式
## 如何体验

当前体验有两层访问保护：Netlify 团队站点访问控制，以及应用管理员登录；尚未提供外部访客账号。不要把管理员密码提交到仓库、README、截图或公开消息中。若要让外部访客自行体验，需要项目所有者另行决定是否公开站点，并先提供隔离的只读演示账号。

登录后可按以下流程体验：

1. 在「增长总览」查看工作流入口与待处理概况。
2. 进入「趋势监测」，点击一条新闻打开详情；查看来源链接、采集时间、摘要和机会判断。
3. 在详情中选择「生成内容角度」，进入内容工作台；检查内容、编辑并保存草稿。
4. 打开「人工审核」，提交审核、批准或退回，并查看状态与审核记录。
5. 在获批内容上登记手动发布链接；此操作只记录发布信息，不会替你向社交平台发布。
6. 浏览「数据报表」与「系统设置」，查看可用工作流数据和 RSS 来源配置。
7. 使用右上角语言切换查看中英文界面。

## 功能范围

- RSS 来源抓取、趋势列表与详情查看
- 趋势机会排序和内容角度辅助
- AI 内容生成、草稿保存与版本保护
- 人工审核、审批状态和记录
- 手动发布登记、工作流报表与通知
- PostgreSQL 持久化、后台定时发现任务和失败重试
- 中英文界面、浅色布局

## 数据与演示边界

- RSS 条目来自当前配置的公开订阅源；其他预置趋势和社媒互动样例属于回放/演示数据，不代表实时社媒监测结果。
- 热度评分不等于平台官方热度；没有真实互动数据时，触达、互动与转化不会被当作真实增长结果。
- 目前没有对外开放的社交平台自动发布或互动回流。
- 线上实例是单独的展示工作区，请勿输入客户隐私、账号口令或其他敏感资料。

## 技术栈

Next.js、React、TypeScript、PostgreSQL、Netlify Functions，以及兼容 Chat Completions 的 AI 服务接口。
